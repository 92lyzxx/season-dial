# SeasonDial · 四季转盘 — 使用说明

> 复刻自抖音「琪（＃－.－）」《春生夏长，秋收冬藏》光遇四季转盘
> 在这之上加了时钟：光束就是秒针，转一圈 60 秒，扫过之处地面换季。

## 怎么运行

双击桌面上的 **SeasonDial** 快捷方式即可（等价于运行 `dist\SeasonDial-1.0.0.exe`）。

- 免安装，单文件，105 MB，启动时自解压到临时目录，首次启动约 3–8 秒属正常。
- 不要把 `dist\SeasonDial-1.0.0.exe` 单独拷走后删掉同目录以外的东西——它是完整的单文件程序，可以自由拷贝到任何位置；拷走后记得重建桌面快捷方式。
- 想让它开机就在，右键菜单里勾 **开机自启**。

## 它长什么样

- 桌面直接贴着一个椭圆透视的「四季岛」（**不再画星空背景**，窗口整体透明，只留盘子和文字）：草地圆盘、中央黑洞表盘、盘沿一圈灯珠刻度。
- 一根金色光束从表盘射出，缓缓扫过盘面，**整根针都在盘内**，不会伸出盘沿；被扫过的地面从春绿→夏绿→秋黄→冬雪，以扇形渐次「被画」过去。
- 盘面上一只小黑猫、一只小白鸽，**按一天里的时段换姿态**（见下）。
- 天空还有天气：春飘樱花花瓣、夏有水面白闪光上浮、秋落枯叶、冬下雪；冬季地面整片覆雪，盘沿还压着一圈积雪，刻度换成深色字以便看清。
- 盘下三行：大字真实时间、日期星期节气、当季治愈语录。**三行都带深色描边 + 投影**，所以放在纯白桌面 / 白色窗口上也看得清。

### 四季的样子（春与夏已彻底区分）

| 季节 | 地面 | 天空 | 装饰 |
| --- | --- | --- | --- |
| 春 | 嫩黄绿草地 | 粉白樱花瓣飘落 | 小花点缀 |
| 夏 | **正午明青水面**（亮青绿水 + 荷叶 + 睡莲） | **水面白闪光上浮** | 水面反光、荷叶、睡莲 |
| 秋 | 土黄落叶地 | 枯叶飘落（带叶脉尖头） | 碎叶堆 |
| 冬 | 纯白覆雪 | 雪花 + 柔光 | 盘沿积雪、雪纹 |

### 猫和鸽子的一天

| 时段 | 猫 | 鸽子 |
| --- | --- | --- |
| 5–9 黎明 | 绕盘慢慢走 | 振翅、踱步 |
| 9–17 白天 | 蹲坐看风景（会眨眼） | 踱步 |
| 17–21 黄昏 | 绕盘走 | 振翅 |
| 21–5 夜里 | **蜷成一团睡觉，头上飘 `z z z`** | **头缩进翅膀睡觉** |

## 治愈语录

每季 6 条原创文案，**26 秒随机换一条**（同季不会连着重复，换季必换新），带 1.4 秒淡入淡出，显示为「夏 · 晚风替你收好汗」这种格式。

- 春：风一暖，种子就醒了 / 把心事交给新叶 / 光落在肩上，慢慢发芽 / 春不急，它一层层地开 / 抬头是晴，低头是新生 / 所有等待，都会开花
- 夏：蝉鸣把午后拉得很长 / 晚风替你收好汗 / 树影挪一寸，日子慢一分 / 热是热的，心要凉一点 / 把西瓜最甜的一勺留给自己 / 水面把光揉碎，洒了一地
- 秋：叶子落地，也算回家 / 把收成装进陶罐 / 凉一点的风，适合想念 / 光变薄了，心事变厚 / 落下的，都是温柔的 / 秋天把答案写在颜色里
- 冬：雪落无声，你也可以慢 / 把手揣暖，把话说轻 / 白是最安静的答案 / 冷的时候，靠近一点就暖 / 等一场雪，也等一个念头 / 冬天教人把日子过慢

（原「春·万物赴光而来」等句已被替换，不再出现。）

## 季节怎么判定的

「跟随真实季节」不是按月份粗分，而是按 **太阳视黄经** 算出立春 / 立夏 / 立秋 / 立冬的**精确时刻**，从这一刻起才算换季。

- 例：2026 年立冬是 11 月 7 日 17:51，那么 11 月 7 日 17:51 之前仍是秋，之后是冬。
- 顶上的节气名同样是算出来的 24 节气（每 15° 一个），不是查表。
- 精度：与紫金山天文台 / 香港天文台历书对照，同一节气**日期全对**，时刻相差在 15 分钟以内（2026 立春官方 04:02，本程序 03:55）。这个偏差只影响换季瞬间的十几分钟，不影响任何一天显示哪个季节。

## 操作

| 动作 | 效果 |
| --- | --- |
| 左键按住拖动 | 移动桌宠（窗口跟着光标走），位置会记住，下次启动回到原地 |
| 左键单击盘面 | 荡开一圈金色涟漪 |
| 右键 | 打开菜单（**点桌面 / 点别的窗口 / 按 Esc，菜单都会自动收起**） |

右键菜单里的项：

- **季节**：**自动轮转（默认）** / 跟随真实季节 / 定格·春·夏·秋·冬
- **转盘**：显示时钟、十二刻度（两个开关）
- **轮转间隔**：**60s（默认）→ 90s → 180s → 360s** 循环切换
- **窗口**：**小 380×268 / 中 500×352（默认）/ 大 650×458**，按窗口中心缩放，超出屏幕会自动拉回来
- **窗口置顶、鼠标穿透（默认不勾）、开机自启**
- **退出**

首次启动（没有存档时）窗口出现在**屏幕右上角**，留 24px 边距；之后按你拖动过的位置恢复。

鼠标穿透：默认关闭——想点后面的窗口，在菜单里勾上「鼠标穿透」即可（勾上后除盘面外的地方都能点穿）。托盘区也有图标，右键可退出。

## 窗口尺寸与文字排版

三档都比第一版缩了一号，桌面占位更小。盘下三行文字是**按窗口剩余高度自适应**算的，小档也不会被窗口底边切掉。

## 性能（实测）

- **渲染限帧 30fps**（桌面宠物不需要 60fps），页面不可见时直接停画。
- 底层大块（侧壁、地面贴图、暗角）缓存成一张离屏画布，每帧只 `drawImage` 一次；换季扫动只叠加「扫过的扇形」，不重画整盘。（盘下那层椭圆投影已去掉，盘体直接贴桌面。）
- 实测（1920×1080、默认中档 500×352、16 核机器）：**CPU 约 18%–23% 单核（≈1.2%–1.5% 总占用，扫季时会到 23%）**，内存工作集合计约 **430MB**（Electron 五进程基线：主进程 + GPU + 渲染 + 工具进程）。
- 想再省电：把窗口切到小档（380×268），或直接退出（托盘右键 → 退出）。
- 想让内存再降一档只能换掉 Electron（原生 C++/Rust 重写），代价远大于收益，暂不做。
- 想临时放开帧率看更顺滑的扫动：源码运行时可加 `?fps=60`（打包版不带参数）。

## 配置存在哪

- 窗口位置与尺寸：`%APPDATA%\SeasonDial\window-state.json`
- 其它偏好（季节模式、轮转间隔、尺寸档、置顶、穿透等）：渲染进程的 `localStorage` 键 `fs-turn-cfg`
- 想恢复默认：关掉程序，删掉 `window-state.json`，并在应用里右键菜单把偏好改回去（或清掉该应用数据）

## 从源码改

```
cd season-dial
npm install
node node_modules\electron\install.js   # 若 electron 二进制没落盘，需带 ELECTRON_MIRROR 手动补
npx electron .                          # 直接跑源码
npx electron-builder --win portable --x64   # 重新打包
```

打包前必须先关掉正在运行的旧实例（exe 会被占用锁住）：

```
Get-Process -Name "SeasonDial" | Stop-Process -Force
```

改画面主要在 `renderer\app.js`：

- `PAL` 四季配色 + `quotes` 语录
- `buildTexture()` 地面贴图（草叶、花、荷叶、睡莲、落叶、雪纹）
- `buildBeamSprite()` 光束在地面的光锥
- `sky` / `updateSky` / `drawSky` 天空天气粒子（`SKY_N` 控制每季数量）
- `drawSnowCap()` 冬季盘沿积雪
- `daypartNow` / `drawCat` / `drawDove` / `drawZzz` 猫鸽分时段状态
- `TERM_LONG` / `sunLong` / `findTermJd` / `realSeason` 节气与换季
- `drawWall / drawSurface / drawRim / drawAnimals / drawHub / drawHands / drawBeam / drawCaption`
- `MENU_DEF` 右键菜单

改窗口行为看 `main.js`：`resizable`、鼠标穿透轮询、拖动轮询、`pet:resize`。

改完想先看效果，不用打包：

```
.\node_modules\electron\dist\electron.exe tools\capture.js
python tools\montage.py
```

会生成 `tools\out\*_preview.png` 和 2×4 联系表 `tools\out\sheet.png`。
调试参数直接走 URL：`?season=winter&wipeTo=spring&wipeP=0.5&clock=0`，时段可用 `?part=night`。
（判断色晕一律看 PNG，JPEG 预览的色度采样会在亮绿盘沿造出假绿边。）

校验节气：`node tools\verify_terms.js`，会打印 2025–2028 全部 24 节气时刻。

## 已知情况

- 程序本身没有代码签名，Windows 首次运行可能弹 SmartScreen 提示，点「更多信息 → 仍要运行」。
- 窗口是透明无边框置顶窗，任务栏不显示它的条目，只在托盘里。
- 窗口尺寸档位是小/中/大固定三档，鼠标拖边框不会拉伸（没有原生边框）。
- 内存约 420MB 是 Electron 的固有基线（主进程 + GPU + 渲染进程），不是画面资源泄漏；长时间运行不会持续上涨。
- 开发用的离屏截图脚本 `tools\capture.js` 已做了管道保护：即便终端提前关掉，也不会再弹 `EPIPE: broken pipe` 的 JS 错误框（该报错只来自截图脚本，与桌宠无关）。
